## About Me

I'm a Site Reliability Engineer with 8+ years of experience building and maintaining reliable infrastructure at scale. Currently working at **Improving**, where I help teams ship faster without breaking things.

I started as a Linux SysAdmin and gradually moved into the DevOps world, eventually landing in SRE - automating everything I could get my hands on along the way. My core belief is **collaboration and shared responsibility** - great systems are built by great teams, not just great engineers.

When I'm not wrangling Kubernetes clusters or tuning pipelines, I'm usually exploring new tools or writing about what I learn.

- Designed and maintained Datadog dashboards, monitors, and alerts to enhance platform observability and incident detection
- Provided on-call production and non-production support, troubleshooting infrastructure and application issues to ensure high availability

- Implemented multi-tenant Istio Service Mesh in OpenShift clusters

- Implemented service mesh observability using Kiali, Prometheus, and Grafana for traffic visualization and monitoring
- Enabled distributed tracing using Tempo and OpenTelemetry to improve request tracing and debugging
- Established cross-region connectivity between service meshes to support multi-region deployments

- Managed Kubernetes deployments across environments using Kustomize overlays
- Implemented GitOps deployments using ArgoCD Applications for automated Kubernetes delivery
- Configured Kubernetes autoscaling using HPA and KEDA ScaledObjects to support dynamic workload scaling
- Automated creation of Datadog dashboards, monitors, and synthetic tests using Terraform

### Security & Governance
- Deployed and configured Kyverno policy engine using Helm to enforce Kubernetes security and governance policies
- Implemented Kyverno Policy Reporter with Slack alerts for policy violation notifications
- Deployed Kube Prometheus Stack (Prometheus, Alertmanager, Grafana) for cluster monitoring and alerting
- Built custom Grafana dashboards using PromQL and configured alerts via Alertmanager
- Implemented distributed tracing using Jaeger for microservices observability
- Secured Kubernetes policy enforcement using RBAC and Network Policies
- Implemented mTLS using Istio Service Mesh for secure service communication
- Integrated Kyverno CLI into GitHub Actions to automate policy validation in CI pipelines
- Implemented GitOps-based policy management using ArgoCD, enabling synchronization across multiple clusters
- Implemented container image verification using Trivy and Cosign to enforce trusted images
